# Two of these are load-bearing and must not be bumped casually:
#
#   langfuse<3   — langfuse_setup.py uses the v2 API
#                  (langfuse.callback.CallbackHandler, client.trace()).
#                  v3 removed both. The ImportError is caught and only
#                  printed, so installing v3 silently disables ALL tracing.
#
#   chromadb     — a persisted chroma_db/ written by a different chromadb
#                  minor version is unreadable by this one, which used to
#                  make dense retrieval fail silently and degrade hybrid
#                  search to BM25-only. rag.py now detects and rebuilds,
#                  but keeping the pin avoids the rebuild entirely.
# ============================================================

# NOTE: torch / sentence-transformers / transformers are deliberately ABSENT.
#
# Embeddings run on chromadb's bundled ONNX build of all-MiniLM-L6-v2 - the
# same model, without PyTorch. Measured whole-app resident set:
#     with torch     1,025 MB   (over the 1 GB free-tier ceiling)
#     with ONNX        ~400 MB
# langchain-core's transformers import is wrapped in try/except, so its
# absence degrades gracefully rather than breaking.
#
# The cross-encoder reranker DOES need sentence-transformers. It is optional:
# without it the destination filter still gates out-of-corpus destinations
# (verified 7/7), you only lose relevance ordering within a destination.
# To develop with it locally:
#     pip install sentence-transformers==3.3.1
# and leave RERANK_ENABLED=true. On a 1 GB host set RERANK_ENABLED=false.
